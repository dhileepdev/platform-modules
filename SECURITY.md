# Security policy

## Supported versions

Only the latest tag on `main` is supported. Older tags are kept for reference and are not patched.

## Report a vulnerability

Use GitHub's private vulnerability reporting on this repository (Security → Report a vulnerability). Please include the affected file or module, a minimal reproduction, and the impact you believe it has.

Do not open a public issue for a suspected vulnerability.

## What to expect

- Acknowledgement within 5 working days.
- An assessment and, when warranted, a fix on `main` with a tag.
- No bug bounty is offered.

## Scope

Terraform modules, the local example, and the CI workflows in this repository. The demo AWS account and any credentials used during the timeboxed run are operator-owned and out of scope; never include credentials, account IDs you do not own, or live ARNs in a report.
